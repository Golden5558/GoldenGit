⚖ cadre juridique & réglementaire
Base légale
Intérêt public (art. 9.2.j RGPD) ou consentement dynamique opt-in. Référentiel CNIL EDS obligatoire. Pas de CPP requis si données déjà collectées.
Consentement éclairé obligatoire (code santé publique). Double consentement : participation à la recherche + traitement des données (RGPD art. 6). CPP obligatoire pour les RIPH.
Autorisation CNIL
Déclaration de conformité
Référentiel CNIL EDS suffisant. Pas d'autorisation au cas par cas si le périmètre est respecté.
Variable selon la RIPH
MR-001 (interventionnel) ou MR-003 (non-interventionnel) selon le type. Parfois autorisation spécifique CNIL au-delà des MR.
Consentement patient
Opt-in granulaire
Par étude, par jeu de données, par durée. Révocable. Traçé sur blockchain = preuve immuable.
Opt-in binaire par protocole
Un consentement = un essai. Ré-consentement requis à chaque amendement de protocole. Papier ou e-consent.
Données rétrospectives vs prospectives
Rétrospectif natif
Accès immédiat aux données déjà dans l'EDS. Études en vie réelle sans recrutement patient.
Prospectif uniquement
Données collectées au fil de l'étude. L'AAP DAtAE interdit les données prospectives dans les EDS publics.
💶 modèle économique
Coût de mise en place
2 M€/an pendant 5 ans (phase développement), puis 3 M€/an (fonctionnement nominal) pour un EDS hospitalier de taille moyenne — estimation HDH 2023. Pour Mon Cercle Santé : infrastructure blockchain + API partenaires.
Variable : quelques milliers € (étude observationnelle) à plusieurs millions (essai multinational multisite). Convention unique fixe les coûts standardisés par acte (réévalués à la hausse en août 2024).
Qui paie ?
Chercheur/labo paie l'accès
Tarification à la mise à disposition (en cours de standardisation — AP-HP, CHU Montpellier). Recherche publique : gratuit (HDH). Privé : redevance.
Promoteur paie tout
Promoteur (labo pharma, CRO, hôpital) finance : inclusion des patients, actes de recherche, rémunération investigateurs, surcoûts établissement.
Récompense patient
Points prévention diabète
Mon Cercle Santé : points échangeables contre avantages thématiques (prévention, prise en charge). Engagement durable.
Indemnisation forfaitaire
Remboursement frais ou indemnité forfaitaire par visite, fixée dans la convention unique. Ponctuel, non thématique.
Scalabilité revenus
SaaS / API récurrent
Un même dataset peut être vendu/accédé par N chercheurs en parallèle. Modèle revenus récurrents à coût marginal faible.
Linéaire par protocole
Chaque nouveau contrat = nouvelle négociation, nouveau CPP, nouveau budget. Pas de levier d'échelle sur la donnée.
🔬 qualité & type de données pour le chercheur
Nature des données
Données de vie réelle (RWD) : longitudinales, continues, multicapteurs (CGM, glycémie, HbA1c, ordonnances). Reflètent le quotidien du patient diabétique.
Données de protocole : très contrôlées, standardisées, validées selon ICH E6. Biais de sélection (patients éligibles ≠ population réelle). Visites planifiées.
Richesse / granularité
Haute granularité patient
Consentement par jeu de données : le chercheur sait exactement quelles variables sont disponibles et consenties. Données enrichies par le patient lui-même.
Granularité protocole
Définie a priori dans le CRF. Ce qui n'est pas dans le protocole n'existe pas. Changements = amendement CPP.
Taille de cohorte accessible
Potentiel 5M patients FR
L'EDS croît avec la plateforme. Pas de plafond lié à un protocole. Requêtes sur cohortes existantes.
Limitée par recrutement
Cohorte = N patients recrutés sur durée déterminée. Compléter ou étendre = nouvel essai.
Valeur scientifique
Real World Evidence (RWE) : puissant pour études épidémiologiques, pharmaco-épidémiologie, IA médicale. Limite : pas randomisé → biais potentiels.
Gold standard scientifique (RCT) : causalité démontrée, niveau de preuve maximal pour AMM. Limite : coût, délais, biais de sélection.
⏱ délais & processus d'accès
Délai d'accès aux données
Semaines (idéal)
Accès quasi-immédiat si l'EDS est constitué et le consentement en place. Objectif Mon Cercle Santé : API requête → données consenties disponibles sous 2-4 semaines.
12-24 mois minimum
CPP : 45 jours. CNIL si hors MR : +60 jours. Négociation convention : 3-6 mois. Recrutement : 6-18 mois. Premier patient inclus ≈ 12 à 24 mois après l'idée.
Complexité administrative
Faible (si EDS autorisé)
Déclaration de conformité CNIL une fois pour toutes. Contrat d'accès type. Pas de CPP par projet si données existantes.
Très élevée
CPP, CNIL (MR ou autorisation spécifique), convention unique par site, budget investigateurs, assurance promoteur, monitoring, audit trail.
Flexibilité en cours d'étude
Haute
Nouvelles variables ? Nouveau consentement ajouté en temps réel. Élargissement de cohorte sans refaire de procédure.
Très faible
Tout changement = amendement au protocole → CPP + CNIL + convention. Peut prendre 3-6 mois supplémentaires.
Recommandation pour Mon Cercle Santé — modèle hybride

L'EDS est le socle stratégique : il capture la valeur longitudinale, scalable et récurrente. Le contrat de recherche clinique reste complémentaire pour les études prospectives interventionnelles à fort niveau de preuve. Les deux se renforcent — l'EDS nourrit l'hypothèse, l'essai clinique la valide.

EDS en priorité pour…
Pharmaco-épidémiologie, RWE, IA médicale, études de cohorte diabète, accès multiple chercheurs, revenus récurrents, études rétrospectives. → le business model principal.
Contrat clinique en complément pour…
Essais interventionnels (nouveau médicament, dispositif), études nécessitant RCT, dossier AMM. → option premium sur cohorte identifiée via l'EDS.
