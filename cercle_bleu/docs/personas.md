# Problématiques — Cercle Bleu

---

## Focus Principal : Patient / Chercheur

### Problèmes

**Du côté patient :**
* manque de clarté sur le partage de données
* sentiment de perte de contrôle sur ses données de santé
* aucun retour sur l'utilisation de ses données (études, résultats)
* données éparpillées entre appareils et acteurs

**Du côté chercheur :**
* qualité et quantité de données insuffisantes (suivi longitudinal)
* temps d'accès trop long pour constituer une cohorte
* standardisation des données difficile
* conformité RGPD lourde à prouver

### Personnas

**Patient (persona principal) :**

Nom : Jean-Pierre
Age : 58
Activité : Comptable
Diabète : Type 2, diagnostiqué il y a 6 ans
Caractéristique : Altruiste, novice en tech mais motivé

Conséquence: HbA1c qui dérive entre les consultations sans que personne ne le voit. Sentiment d'impuissance. Données Dexcom qui s'accumulent sans jamais servir à rien.

**Recherche publique (persona secondaire) :**

Nom : Huguette
Age : 52
Activité : Chercheuse
Caractéristique : Pointilleuse
Problème : Mauvaise qualité donnée, format hétérogène, temps d'accès long
Conséquence : Mauvaise qualité d'étude, inertie

**Labo privé (persona secondaire) :**

Nom : Silvie

Activité : CTO
Caractéristique : Pragmatique
